# Comparing_Planetary_Evolution_Models
This repository contains the analysis notebooks used to compare the results of three planetary evolution code (MESA, CEPAM, Completo). The original simulations are not included here, as they consist mainly of internal test notebooks and raw model runs.
This repository focuses solely on the comparative analysis, where the outputs from all three projects are combined, processed, and visualized.

The notebooks in the comparisons/ directory demonstrate the full analysis workflow:
- Loading the evolution datasets from all three projects
- Interpolating the model outputs to extract consistent values across different masses, temperatures, and core masses
- Structuring and preprocessing the data into a uniform format
- Creating summary tables of key planetary parameters
- Generating comparison plots that highlight differences between the models
- Interpreting the results and summarizing the trends observed across simulations
These notebooks represent the core of the project: understanding how planets with different physical characteristics evolve over time and how these models compare.
